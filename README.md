# My To-Do List

A simple to-do list website. Add tasks, check them off, and delete them.
Tasks are saved in your browser, so they're still there when you come back.

## How to use it

Open `index.html` in any web browser. That's it — no installation needed.

## Files

- `index.html` – the page structure
- `style.css` – how it looks (works on phones and computers, supports dark mode)
- `app.js` – how it works (adding, checking off, deleting, saving tasks)
